* What is the primary defense against this attack?
Answer: The primary defense is the use of Parameterized Queries. This method ensures that user input is never interpreted as executable SQL code. By separating the query logic from 
the data, the database treats malicious payloads like ' OR 1=1 -- as simple text strings rather than commands, effectively neutralizing the injection attempt.
